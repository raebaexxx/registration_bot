# 🎲 Board Games Registration Bot

[![CI](https://github.com/raebaexxx/registration_bot/actions/workflows/ci.yml/badge.svg)](https://github.com/raebaexxx/registration_bot/actions/workflows/ci.yml)

Telegram-бот для записи на настольные игры. Подходит для канала, где каждые выходные проходят взрослые и подростковые игры: «Мафия», «Бункер» и любые другие.

Бот не привязан к конкретным играм. Админ сам создаёт встречу, добавляет игры, указывает время и количество мест. Игрок выбирает категорию, игру и записывается в один клик.

## Возможности

### Для игрока

- Выбор категории: **взрослые** или **подростковые** настолки.
- Список игр ближайших выходных с живым счётчиком: `занято 36 из 50 · свободно 14`.
- Запись в один клик — Telegram ID, имя и `@username` берутся из профиля. ФИО и телефон не нужны.
- Раздел «Мои записи» с возможностью отменить запись.
- Лист ожидания, если мест нет: бот показывает позицию в очереди.
- Если кто-то отменил запись, первому в листе ожидания приходит предложение занять место. На ответ есть 2 часа (настраивается).
- Напоминания за 24 часа и за 2 часа до игры.
- Кнопка «Записаться» в анонсе канала открывает нужную игру прямо в боте.

### Для админа

- Админ-панель прямо в Telegram: `/admin`.
- Создание встречи на любую дату, быстрые кнопки «ближайшая суббота / воскресенье».
- Добавление игр по шагам: категория, название, время, количество мест, место проведения, описание.
- Копирование всех игр с прошлой встречи — чтобы не вводить заново каждую неделю.
- Публикация встречи и отправка анонса в канал.
- Список участников с именем, `@username` и Telegram ID.
- Уведомления админам о новых записях, отменах и занятых местах из резерва.
- Удаление участника, изменение лимита мест, закрытие/открытие записи, отмена игры с уведомлением участников.
- Архив прошлых встреч.
- Несколько админов через список ID в `.env`.

## Стек

- Python 3.11+ (в Docker используется 3.12)
- [aiogram 3](https://docs.aiogram.dev/) — Telegram Bot API
- SQLAlchemy 2 (async) + SQLite
- Alembic — миграции
- APScheduler — напоминания, истечение предложений, авто-закрытие игр
- Docker + Docker Compose

## Быстрый старт

### 1. Создай бота

1. Открой [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправь `/newbot`, придумай имя и username.
3. Сохрани токен вида `123456789:AA...`.

### 2. Подготовь канал

1. Добавь бота в канал как администратора.
2. Дай право **«Публикация сообщений»**.
3. Узнай ID канала:
   - для публичного канала можно указать `@channel_username`;
   - для приватного — перешли любой пост из канала в [@userinfobot](https://t.me/userinfobot) и возьми ID вида `-1001234567890`.

### 3. Узнай свой Telegram ID

Напиши [@userinfobot](https://t.me/userinfobot) — он покажет твой ID. Этот ID идёт в `ADMIN_IDS`.

### 4. Настрой `.env`

```bash
cp .env.example .env
nano .env
```

Минимально нужно заполнить:

```env
BOT_TOKEN=123456789:AA...
ADMIN_IDS=123456789
CHANNEL_ID=-1001234567890
```

Полный список переменных:

| Переменная | Обязательна | Описание |
|---|---|---|
| `BOT_TOKEN` | да | Токен из @BotFather |
| `ADMIN_IDS` | да | Telegram ID админов через запятую |
| `CHANNEL_ID` | для анонсов | ID канала или `@username` |
| `TZ` | нет | Часовой пояс, по умолчанию `Europe/Moscow` |
| `DATABASE_URL` | нет | По умолчанию `sqlite+aiosqlite:///./data/bot.db` |
| `WAITLIST_OFFER_MINUTES` | нет | Сколько действует предложение места, по умолчанию 120 минут |
| `ADMIN_NOTIFICATIONS` | нет | Уведомлять админов о записях и отменах, по умолчанию `true` |
| `LOG_LEVEL` | нет | `INFO`, `DEBUG`, `WARNING`, `ERROR` |

### 5. Запуск локально

```bash
make install
make migrate
make run
```

Или вручную:

```bash
python3 -m venv .venv
.venv/bin/pip install -e ".[dev]"
.venv/bin/alembic upgrade head
.venv/bin/python -m app.main
```

### 6. Запуск на VPS через Docker

На сервере (если Docker ещё не установлен):

```bash
sudo apt update
sudo apt install -y curl
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER
# перелогинься, чтобы применилась группа
```

Вариант из репозитория Ubuntu — обязательно вместе с плагином Compose:

```bash
sudo apt update
sudo apt install -y docker.io docker-compose-v2
```

Клонируй репозиторий и настрой `.env`:

```bash
git clone https://github.com/raebaexxx/registration_bot.git
cd registration_bot
cp .env.example .env
nano .env
chmod 600 .env
```

Запуск:

```bash
docker compose up -d --build
docker compose logs -f --tail=200
```

Бот работает в polling-режиме, открывать порты не нужно. Контейнер сам применяет миграции при старте.

Обновление после изменений:

```bash
git pull
docker compose up -d --build
```

Или одной командой:

```bash
./scripts/deploy.sh
```

## Как пользоваться

### Админ

1. Открой бота и отправь `/admin`.
2. «📅 Встречи» → «➕ Создать встречу» → выбери дату.
3. «➕ Добавить игру» → категория → название → время → места → место проведения → описание.
4. Повтори для всех игр.
5. Нажми на игру в карточке встречи → «👥 Участники», чтобы увидеть, кто записан.
6. «✅ Опубликовать» — после этого игры видны игрокам.
7. «📢 Анонс в канал» → проверь предпросмотр → «Отправить в канал».
8. На следующей неделе создай новую встречу и нажми «📋 Скопировать с прошлой встречи».

При новых записях и отменах бот присылает уведомление всем ID из `ADMIN_IDS`: имя, `@username`, Telegram ID, игра и актуальный счётчик мест. В уведомлении есть кнопка «🎲 Открыть игру». Отключить уведомления можно через `ADMIN_NOTIFICATIONS=false`.

### Игрок

1. `/start` → «🎲 Игры».
2. Выбери «Взрослые» или «Подростковые».
3. Выбери игру.
4. Нажми «✅ Записаться». Счётчик обновится сразу.
5. Если мест нет — «⏳ В лист ожидания».
6. Отменить запись можно в «📋 Мои записи» или в карточке игры.

## Как работает лист ожидания

- Когда игра заполнена, новые игроки попадают в очередь.
- При отмене подтверждённой записи место резервируется за первым в очереди.
- Ему приходит сообщение с кнопкой «✅ Занять место».
- Если он не ответил за `WAITLIST_OFFER_MINUTES` (по умолчанию 2 часа), предложение переходит следующему, а первый возвращается в конец очереди.
- Если мест стало больше (админ увеличил лимит), предложения уходят сразу нескольким первым из очереди.

## Напоминания и автоматика

Планировщик проверяет состояние каждую минуту:

- закрывает запись на игры, которые уже начались;
- истекает просроченные предложения из листа ожидания;
- отправляет напоминания за 24 часа и за 2 часа;
- не дублирует напоминания: если человек записался меньше чем за 24 часа до игры, он не получит «завтрашнее» напоминание сразу после записи.

## Резервные копии

SQLite лежит в `data/bot.db`. Сделать консистентный бэкап:

```bash
# локально
make backup

# в Docker
docker compose exec -T bot python -m app.tools.backup
```

Файлы складываются в `backups/`. Пример cron на сервере:

```cron
0 4 * * * cd /opt/registration_bot && docker compose exec -T bot python -m app.tools.backup >/dev/null 2>&1
```

Восстановление: останови бота, замени `data/bot.db` файлом из бэкапа, запусти снова.

## Частые проблемы

**`unknown shorthand flag: 'd' in -d`** — установлен Docker без Compose. Поставь плагин: `sudo apt install -y docker-compose-v2`, затем проверь `docker compose version`.

**`BOT_TOKEN не задан`** — скопируй `.env.example` в `.env` и заполни токен.

**`CHANNEL_ID не настроен`** — добавь ID канала в `.env` и перезапусти бота.

**Анонс не отправляется** — проверь, что бот админ канала и у него есть право публикации. Для приватного канала ID должен начинаться с `-100`.

**Бот не видит команды** — проверь, что контейнер запущен: `docker compose ps` и `docker compose logs -f`.

**Ошибка миграции** — посмотри логи `docker compose logs bot`. Если база повреждена, восстанови из `backups/`.

**Не приходят напоминания** — проверь `TZ` в `.env` и время игры. Напоминания отправляются только подтверждённым записям.

## Безопасность

- `.env` и база `data/` исключены из git.
- Не публикуй токен бота. Если он утёк — перевыпусти через `/revoke` в @BotFather.
- Бот собирает только Telegram ID, имя и `@username`. Никаких ФИО, телефонов и адресов.
